# Gyromania iPhone Demo App

Demo PWA/React app for Gyromania Greek Grill House.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Create a free Vercel account.
2. New Project → Import/Upload this folder.
3. Framework: Vite.
4. Build command: `npm run build`.
5. Output directory: `dist`.

After deployment, open the Vercel link on iPhone Safari and use Share → Add to Home Screen.
